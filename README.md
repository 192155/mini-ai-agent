# 🤖 Mini AI Agent

A multi-functional AI assistant built with Python, Gemini AI,
PDF RAG, Web Search, Calculator, Memory, Voice and Image Analysis.

---

## 🚀 Features

### 🤖 Gemini AI
General questions and conversations using Gemini.

### 📚 PDF RAG
Upload PDF documents and ask questions about their content.

### 🌐 Web Search
Search the internet for current information.

### 🧮 Calculator
Perform mathematical calculations using natural language.

### 🧠 Chat Memory
Each chat keeps its own conversation history.

### 🎤 Voice Input
Ask questions using your microphone.

### 📷 Image Analysis
Upload an image and ask the AI questions about it.

### 💬 Multiple Chats
Create, switch between and delete conversations.
